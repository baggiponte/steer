# Triage Labels

| Role              | Local status        | Meaning                                |
| ----------------- | ------------------- | -------------------------------------- |
| `needs-triage`    | `needs-triage`      | Needs evaluation                       |
| `needs-info`      | `needs-info`        | Waiting for more information           |
| `ready-for-agent` | `ready-for-agent`   | Fully specified and ready to implement |
| `ready-for-human` | `ready-for-human`   | Requires human judgment or action      |
| `wontfix`         | `wontfix`           | Will not be actioned                   |
